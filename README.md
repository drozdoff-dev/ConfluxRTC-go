# ConfluxRTC-go

> **Scalable SFU & Signaling platform built in Go — open foundation for real-time video communication.**

---

## 💡 Идея проекта

**ConfluxRTC-go** — это open-source фундамент для построения систем видеоконференций и real-time коммуникаций, основанный на современных принципах микросервисной архитектуры и протоколе WebRTC.  

Проект создаётся как **ядро (foundation)**, на котором можно развернуть собственный аналог Zoom / Jitsi / Daily / LiveKit, но с фокусом на:
- минимализм и прозрачность кода (Go);
- модульность и горизонтальное масштабирование;
- чистую архитектуру и тестируемость;
- простоту деплоя (Docker / Kubernetes).

---

## 🧱 Концепция

В основе ConfluxRTC лежат четыре ключевых сервиса:

1. **API Gateway** — единая точка входа (REST + WebSocket), маршрутизация запросов.  
2. **Room Service** — CRUD-сервис для управления комнатами (gRPC + Redis/Postgres).  
3. **Signaling Service** — WebSocket-диспетчер, обеспечивающий обмен SDP/ICE между участниками.  
4. **Media Server (SFU)** — сервер пересылки медиапотоков на базе [Pion WebRTC](https://github.com/pion/webrtc).

Эта комбинация создаёт основу для построения масштабируемой WebRTC-инфраструктуры — от маленьких MVP до production-систем с тысячами одновременных звонков.

---

## 🏗 Архитектурные принципы

- **Микросервисы:** каждый компонент — независимый, изолированный и легко масштабируемый.  
- **Clean Architecture:** бизнес-логика отделена от инфраструктуры.  
- **API-first:** gRPC для внутренних вызовов, REST для внешних.  
- **Stateful/Stateless баланс:** Signaling stateful, Room stateless.  
- **Контейнеризация:** всё разворачивается через Docker Compose, затем Kubernetes.  
- **Модульность:** легко добавлять новые сервисы (чаты, запись, нотификации).

## 🚀 Цель MVP

**MVP** ConfluxRTC-go — это рабочая система, которая:
- позволяет создать временную комнату;
- подключить несколько участников через WebSocket-сигналинг;
- установить WebRTC соединения между ними;
- пересылать аудио/видео через SFU-сервер (на базе Pion).

---

## 🔭 Дальнейшее развитие

После MVP планируется развитие в сторону:
- записи звонков и стриминга в S3;
- текстовых чатов;
- аналитики качества соединения;
- управления ролями и правами (модерация);
- облачной (SaaS) версии ConfluxRTC.
